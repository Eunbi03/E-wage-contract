# E-wage-contract
전자임금계약서 (Google Apps Script 웹앱) — 신규입사자 / 기존 직원 연봉갱신 공용.

전자근로계약서와 같은 구조(시트 저장, LockService, 중복 제출·승인 방지, 관리자 비밀번호,
작성/수정/설정/관리 탭, 서명 캔버스, 발송큐 + SMS/이메일, 직인, 조항템플릿 시트)를 그대로 쓴다.

## 배포 전 준비
- Apps Script 프로젝트 파일: `Code.gs`, `Index.html`, `Seals.html`(전자근로계약서와 같은 `const sealImages = { '법인명': 'data:image/...' }`)
- 스크립트 속성: `SOLAPI_API_KEY`, `SOLAPI_API_SECRET` (문자 발송 시)
- 고급 서비스 `Drive API` (완료 계약서 PDF 자동 보관 시, 없으면 HTML만 보관)
- 법인별 발신 이메일(설정 탭 → 법인 수정 → 발신 이메일): 스크립트 소유자 Gmail의 [설정 → 계정 → 다른 주소에서 메일 보내기]에 등록·인증된 주소여야 한다. 비워두면 스크립트 소유자 계정으로 발송.
- 법인별 문자 발신번호(설정 탭 → 법인 수정 → 문자 발신번호): Solapi 콘솔에 등록된 발신번호여야 한다. 비워두면 담당자연락처로 발송.
- 최저시급(설정 탭 → 새 계약서 초기값): 매년 1월에 갱신. 이보다 낮은 시급은 작성 탭에서 경고만 하고 발송은 막지 않는다.
- 임금테이블 시트: `영업기본`, `영업(35시간)`, `영업(37.5시간)`, `사무&생산`, `감시적단속자`
  - 열 구성(1행 헤더): B 연봉 · C 월지급액 · D 기본급 · E 연장수당 · F 야간수당 · J 기본시간 · K 시급 · L 연장시간 · M 야간시간

나머지 시트(계약대기, 승인대기, 계약목록, 발송큐, 회사설정, 기본값설정, 메시지템플릿, 조항템플릿)는 처음 사용할 때 자동으로 만들어진다.
